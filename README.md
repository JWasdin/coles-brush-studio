# Cole's Brush Studio — Lo-fi Mocks

Lo-fi concept mocks for **Cole's brush studio** — a simple, crisp site for a certified
nail technician's natural nail painting + nail care booking, alongside a painted-silks
showcase.

## Current direction: "Color Ritual"

Neutral, peaceful watercolor canvas (warm cream, soft washes) that lets bright
nail colors and silks pop. Serif display type + clean sans body copy.

- Arched watercolor hero with nail polish still life
- Dual pathways: **Painted silks** gallery (wide button → modal with detail/grid
  views, per-piece **Inquire** buttons — silks are sold by inquiry, not online)
  and **nail service booking** (three service tiles → split-layout booking modal:
  service details left, scheduling form right)
- Warm-cream footer with palette swatches

## Files

- `index.html` — the full concept page (open it directly in a browser)
- `assets/` — imagery used by the page

> These are lo-fi concepts, not production code. The booking and inquiry flows
> are prototypes with placeholder content.
